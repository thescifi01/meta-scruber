# Meta-Scruber

## 🧾 Overview
**Meta-Scruber** is a lightweight and easy-to-use web-based tool designed to remove metadata from images. Metadata often contains hidden information such as camera details, timestamps, GPS location, editing history, and sometimes AI-generated tags. While this data can be useful in certain contexts, it may also raise privacy concerns or reveal unnecessary details when sharing images online.

This project was originally built for personal use but is now available publicly for anyone who wants a simple and effective way to clean image files before sharing them.

---

## 🎯 Purpose
In today’s digital world, images carry more than just visual content. Hidden metadata can expose:
- Location data (GPS coordinates)
- Device and camera information
- Editing software details
- AI-generated content markers

Meta-Scruber helps you:
- Protect your privacy
- Remove unnecessary or sensitive information
- Prepare images for safe sharing
- Clean AI-generated metadata tags

---

## ✨ Features
- 🖼️ Upload any image easily  
- 🧹 One-click metadata removal  
- ⚡ Fast and lightweight processing  
- 🔒 No data stored or sent to servers (client-side processing)  
- 📥 Download clean, metadata-free image instantly  
- 🌐 Works directly in the browser (no installation required)  

---

## 🛠️ How It Works
Meta-Scruber processes images directly in your browser using JavaScript. When you upload an image:

1. The image is loaded into memory  
2. Metadata is stripped during processing  
3. A new clean version of the image is generated  
4. You can download the cleaned file instantly  

This ensures:
- No server interaction  
- No data tracking  
- Complete privacy

## ⚠️ Important Notes
- This tool removes standard metadata but may not guarantee removal of all embedded AI identifiers depending on format and encoding.  
- Works best with common formats like JPEG and PNG.  
- Since processing happens in-browser, large files may take slightly longer depending on your system performance.
